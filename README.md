# Employee Management SQL Analysis

## 📌 Project Overview

This project demonstrates SQL-based analysis of employee, department, salary, manager, and project data using MySQL.

The goal is to use SQL to answer business questions and generate meaningful insights from relational data.

## 🎯 Project Objectives

- Analyze employee salary data
- Compare salaries across departments
- Identify highest-paid employees
- Analyze employee-manager relationships
- Analyze project assignments and workload
- Rank employees within departments
- Calculate department-level salary statistics
- Practice advanced SQL techniques

## 🗄️ Database Tables

### Employees
Contains employee details including:

- Employee ID
- Employee Name
- Department
- Manager
- Salary
- Hire Date

### Departments
Contains:

- Department ID
- Department Name

### Projects
Contains:

- Project ID
- Project Name
- Department ID

### Employee_Projects
Contains:

- Employee ID
- Project ID
- Project Hours

## 🔍 Key Analysis

The project includes queries to:

1. Find employees earning above the company average
2. Compare employee salaries with department averages
3. Find the highest-paid employee in each department
4. Rank employees based on salary
5. Find the top 2 employees in each department
6. Compare employee salaries with their managers
7. Calculate department-wise average salary
8. Identify departments with the highest salary levels
9. Analyze employees working on multiple projects
10. Calculate total project hours
11. Identify employees without project assignments
12. Analyze salary differences from department averages

## 💡 Business Insights

The SQL analysis can help organizations understand:

- Salary distribution across departments
- High-performing salary groups
- Department-level compensation patterns
- Employee workload
- Project resource allocation
- Manager-employee salary relationships
